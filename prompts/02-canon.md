# 02 · Design canon

**When:** after you approve the plan.
**Output:** `design/canon.md`, `design/glossary.tsv`, `design/formula-sheet.md`, `design/formula-vectors.json`.

```text
I approve the plan. Still no code.
Write every rule, number and name of the game into design/canon.md (keep the section order of the current file).
Use integers only: lengths in units, time in ticks, chances in per mille.
Write every formula into design/formula-sheet.md with 4-6 test vectors each, and the same vectors into design/formula-vectors.json.
Add every game term to design/glossary.tsv (concept, en, tr, note). One term means one thing.
Add balance targets that a bot simulation can check.
```

**Check:** every number in the canon has a name; every formula has vectors; balance targets are measurable.

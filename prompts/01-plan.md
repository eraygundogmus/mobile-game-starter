# 01 · Idea and plan

**When:** day 1, before any code.
**Output:** a plan you can approve or change.

```text
I want to make a mobile game: <one-sentence idea, e.g. "a one-finger arcade game where blocks fall and you dodge them">.
It runs on iOS, Android and the web from one codebase.
Do not write code yet.
Write a plan with: the core loop, the session length, the screens, the systems,
the tech layout (pure TypeScript engine, Expo app, Cloudflare Workers server) and the first milestone.
List the open decisions I must make.
```

**Check:** the loop fits in one sentence; the first milestone is playable offline; open decisions are listed.

```text
Telefonda oynanan bir oyun yapmak istiyorum: <tek cümlelik fikir>.

(saf TypeScript motor, Expo uygulama, Cloudflare Workers sunucu) ve ilk kilometre taşını bir plan olarak çıkar.
Benim vermem gereken kararları listele.
```
